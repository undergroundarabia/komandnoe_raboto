# командная работа

типа магазин обуви оли и поли

## что можно

- просмотр всех товаров
- поиск по названию
- фильтрация по категории
- сортировка по цене
- постраничный просмотр каталога
- добавление, изменение и удаление товаров
- вывод доступных размеров и количества товара

## что использовали

- c# и .net 8
- ef core
- mssql

## как запустить

1. выполнить скрипт Database/ShoeStoreDb.sql в Microsoft SQL Server
2. перейти в каталог приложения: cd ShoeStore
3. восстановить зависимости: dotnet restore
4. запустить приложение: dotnet run

## кто что делал

- поля: модель данных, настройка бд и ef core
- оля: CRUD операции, чтение, поиск, фильтрация, сортировка, пагинация и отображение каталога
